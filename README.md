What do I use on my setup:

- **Window manager:** [swaywm](./swaywm/sway/)
- **Status Bar:** [waybar](./swaywm/waybar/)
- **Terminal:** [kitty](./Terminal/)
- **Shell:** [zsh](./zsh/)
- **Editor:** [neovim](./nvim/)
