# Terminal

> I use kitty on my system, and my old setup used alacritty. I keep both configs here, it looks alike.

## **Prerequisites:**

Make sure your have these installed:

- **Terminal Emulator:** alacritty/kitty
- **Fonts:** JetBrainsMono Nerd Font

## **How to apply the config:**

Get them to their places:

(for alacritty)
```sh
cp -r ./alacritty/ ~/.config/
```

(for kitty)
```sh
cp -r ./kitty/ ~/.config/
```

## **Disclaimer:**

Since this is tuned specifically for my own workflow, font sizes, and aesthetic preferences, it might look weird or throw parsing errors if your Alacritty/Kitty version is too old.
